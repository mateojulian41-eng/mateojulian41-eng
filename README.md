## Proyectos destacados

### JobTrack | Aplicación web full stack

Aplicación para registrar, organizar y hacer seguimiento a postulaciones laborales.

Incluye:

- Registro e inicio de sesión.
- Autenticación mediante JWT.
- Rutas protegidas y separación de información por usuario.
- Creación, consulta, edición y eliminación de postulaciones.
- Búsquedas y filtros.
- Dashboard con estadísticas.
- Frontend, API y base de datos desplegados.

**Tecnologías utilizadas:** React, Vite, JavaScript, Tailwind CSS, Axios, Node.js, Express, PostgreSQL, Prisma ORM, JWT, Vercel y Render.

- Aplicación: https://jobtrack-fawn.vercel.app
- Repositorio: https://github.com/mateojulian41-eng/jobtrack
- API: https://jobtrack-api-rc04.onrender.com

### NOIR URBANO | Proyecto personal de e-commerce

Plataforma tecnológica de e-commerce para una marca de ropa urbana actualmente en desarrollo.

Incluye:

- Catálogo demostrativo.
- Carrito persistente.
- Flujo de pedidos.
- Persistencia en PostgreSQL.
- Integración de Wompi en sandbox.
- Firma de integridad y webhook validado.
- Seguimiento seguro mediante token.
- Panel administrativo protegido con Clerk.
- Gestión e historial de estados.
- Suite de 72 pruebas automatizadas aprobadas.

**Tecnologías utilizadas:** HTML5, CSS3, JavaScript, Node.js, Neon PostgreSQL, Wompi, Clerk, Git, GitHub y Vercel.

- Aplicación: https://noir-urbano.vercel.app

> La plataforma tecnológica es funcional, pero los productos visibles son demostrativos y la operación comercial continúa en fase de validación.
